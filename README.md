# 🚀 Космическая мультиплеерная игра

Многопользовательская браузерная игра с механикой гравитационных полей.

## ✨ Особенности

- 🌌 Бесконечный космос с процедурной генерацией
- 🪐 Планеты с гравитационными полями
- 👥 Мультиплеер в реальном времени
- 🎯 Цель — добраться до космической станции
- ⛽ Ограниченное топливо
- 💥 Взрывы и частицы

## 🎮 Управление

- **← →** или **A/D** — поворот корабля
- **↑** или **W** — двигатель
- **↓** или **S** — торможение
- **R** — перезапуск

## 🛠 Технологии

- Node.js
- Express
- WebSocket
- HTML5 Canvas

## 🚀 Установка

\`\`\`bash
npm install
npm start
\`\`\`

Откройте `http://localhost:3000`

## 🌍 Деплой

Игра готова к деплою на Render.com, Railway.app или любой другой платформе с поддержкой Node.js.
